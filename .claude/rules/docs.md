# Documentation

Docs live in `docs/` and follow a naming convention:

- `howto-*.md` — task-oriented guides for specific scenarios
- `pattern-*.md` — reusable strategies and conventions

## Rules
- Keep docs **pattern-focused** — explain the why and how within this workspace, link to official docs for mechanical steps
- Update docs when new patterns are discovered during sessions
- Docs are the "translate" destination from the session lifecycle — when session knowledge stabilizes, move it to `docs/`
- Don't duplicate official Claude Code documentation — reference it instead
