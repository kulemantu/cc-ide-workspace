## Testing plan (first-class)

Single source of truth for "is it green?" is the one workspace gate. Sub-lanes exist for fast local loops.

| Lane | Command | Scope | Gate role |
|------|---------|-------|-----------|
| **Workspace gate** | `uv run --project scripts python3 scripts/src/workspace_check.py verify` | pytest + ruff + pyright + app unittest, aggregated | **Blocking** — must be green on `main` (G0-2) and at each branch exit |
| Unit/integration | `cd scripts && uv run pytest` (single: `uv run pytest tests/test_foo.py::test_bar`) | `scripts/src/` modules incl. `agents_sync`, `wsindex`, `sharepack` | Blocking |
| Lint | `cd scripts && uv run ruff check .` | style/lint | Blocking |
| Type | `cd scripts && uv run pyright` | static types | Blocking |
| Per-app unittest | `cd apps/<name> && uv run python3 -m unittest <mod> -v` | stdlib-only portable apps (skip ruff/pyright per app policy) | Blocking for that app |
| Fresh-clone smoke | `uv run pytest` (template smoke test) | proves `scripts/` collects ≥1 test on a clean clone | Blocking (G0-5) |
| Portability | `uv run python3 apps/<name>/<entry>.py --help` from bare env | app lift-out (GF-4) | Blocking at GATE-F |

**Per-item test hooks:** ADPT → `test_agents_sync` (determinism + stale-gate); IDX → `test_wsindex*` (skip-list, invalid-metadata block, date-range); SHARE → `test_sharepack*` (exclusion, media allowlist, manifest reasons, severity split); MCP → placeholder-only + no-secret-in-generated + hostile-schema render.
**Rule (CLAUDE.md):** always Python + always tests; never bare `python`; run via `uv run`. Outputs → `workspace/.outputs/`.
