# workspace/

This is the user's space. It is for notes, documents, data files, and any other files the user is working with.

## Rules

- Do not create scripts or code files here — those belong in `scripts/`
- Do not reorganize, rename, or move the user's files without being asked
- All generated output goes to `workspace/.outputs/` — from scripts, analysis, or any Claude-generated content
- Input files the user places here can be read by scripts in `scripts/`
